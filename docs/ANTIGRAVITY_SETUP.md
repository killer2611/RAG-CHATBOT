# Antigravity Setup

This setup intentionally reuses only workflow/tooling lessons from the previous HackX project.

Reusable lessons:
- freeze architecture before implementation;
- one phase/task per agent turn;
- implement → test → report → stop;
- persist project context in files;
- use the strongest model selectively;
- keep MCP servers few and single-purpose;
- keep skills single-responsibility;
- validate every phase;
- avoid unnecessary framework/backend rewrites.

Explicit exclusion:
The separate AI Interview Agent/HackX product, its endpoint contract, interview logic, candidate model, controller design, follow-up engine, or domain functionality must not be merged into this RAG project.

Current product:
Flagship RAG Knowledge Platform.
